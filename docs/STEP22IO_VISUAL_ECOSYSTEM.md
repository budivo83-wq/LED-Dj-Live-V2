# STEP22IO — VISUAL ECOSYSTEM

Další vrstva nad STEP22IN. Cíl: Show OS se začíná chovat jako živý vizuální vesmír, ne jako playlist efektů.

## Přidáno

- Nová sekce **Visual Ecosystem** v Show OS.
- Universe Director AI metriky: Age, Novelty, Fatigue, Curiosity, Coherence.
- Show DNA / Director Genome: exploration, aggression, mystery, organic, synthetic, cosmic, forge.
- Discovery System: Hidden World / Hidden Civilization / Hidden Weather / Hidden Event / Hidden Journey.
- Mega Events: Black Sun Rise, Infinite Reactor, Galactic Convergence, First Contact atd.
- Show History: uložení souhrnu běhu show.
- Ecosystem Bridge payload do localStorage:
  - `budilight.visual.ecosystem.bridge`
  - současně kompatibilně i `budilight.performance.bridge.pro`

## Důležité

Performance renderer se pořád nepřepisuje. Show OS posílá jen intent/payload.

## Test

1. Spusť aplikaci.
2. Otevři **SHOW OS**.
3. V levém menu otevři **Visual Ecosystem**.
4. Zkus:
   - DIRECTOR PULSE
   - HIDDEN SIGNAL
   - MEGA EVENT
   - SEND ECOSYSTEM BRIDGE
5. Pak zkontroluj Bridge Pro payload.
